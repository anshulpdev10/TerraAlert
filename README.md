
# 🌍 GeoSafe AI – Landslide Prediction & Risk Analysis System

GeoSafe AI is a smart disaster management system designed to predict landslide risks using machine learning and geospatial data analysis. The system processes environmental parameters such as rainfall, terrain, slope, and soil conditions to classify areas into different risk levels (Low, Medium, High).

## 🚀 Key Features
- 📊 Data preprocessing and feature engineering (CRI, terrain factors)
- 🤖 Machine Learning-based risk prediction
- 🗺️ Risk zone classification (Low / Medium / High)
- 📈 Visualization using maps and graphs
- 🚨 Early warning and alert system (future scope)
- 👨‍💻 User dashboard for monitoring and decision-making

## 🧠 How It Works
1. Collects environmental and historical data
2. Cleans and processes the data
3. Applies ML models for prediction
4. Classifies risk levels
5. Displays results via visualization dashboard

## 🎯 Objective
To provide a scalable and intelligent system that helps authorities predict landslides early and take preventive actions, ultimately reducing risk to human life and infrastructure.

## 🛠️ Tech Stack
- Frontend: React.js
- Backend: Node.js / Flask (based on implementation)
- Database: MongoDB
- ML: Python (Scikit-learn / Pandas / NumPy)
- APIs: Weather / Geospatial APIs (GEE, OpenWeather)
